// PROJECT ID: 001 — SAAS RECOMMENDATION SYSTEM

LIKYLY // ARCHITECTURE

A hybrid recommendation pipeline: two specialized model families, tracked and served independently, blended at request time.

Python pgvector MLflow API

Pipeline

01
Content-based layer
TF-IDF combined with sentence-transformer embeddings, stored in pgvector, capture thematic similarity directly from product text — computed at ingestion time, so a brand-new product is recommendable immediately.
02
Collaborative layer
Implicit ALS (Alternating Least Squares) trained on real interaction signals — a purchase carries more weight than a view — with no fabricated 1-5 star ratings.
03
Weighted hybrid
Content and collaborative scores combine through an alpha parameter, tunable per request, so the balance can shift toward content for cold-start cases or toward behavior once enough interaction data exists.
04
Model governance
MLflow tracks and versions each specialized model, so quality can be monitored and rolled back over time — the same discipline applied to a production ML system, not a one-off script.
05
Delivery
Precomputed or low-latency (tens of ms) recommendations are exposed through Python, JS/TS and PHP SDKs, self-hosted end to end — no visitor or catalog data leaves the client's infrastructure.

Cold-Start Handling

A new product becomes recommendable the moment it's ingested — through its content profile and embedding, plus popularity — without waiting for a retraining cycle. The collaborative layer only retrains once enough new interactions accumulate.

// THE LAB: ML-014 · PURE MACHINE LEARNING

GOLF & PERFORMANCE // ARCHITECTURE

A small experiment born on the driving range: can launch-monitor data predict how far a 3-wood shot will carry, and which ball feature matters most?

Python pandas scikit-learn KNN Regression Linear Regression seaborn Jupyter

Pipeline

01
Data
Launch-monitor exports (CSV): carry distance, ball speed, apex, launch angle, dispersion and distance to flag. A first set of 10 real shots, then an extended set of 1,000 shots with the 3-wood.
02
Preparation
Decimal commas converted to floats, rows filtered on the club (n°3), missing carry values dropped, and features min-max normalized for the KNN models.
03
KNN regression
Univariate models first, one feature at a time, to rank the features. Then multivariate models on the best 2, 3 and 4 features, with k tuned from 1 to 3 and compared on RMSE.
04
Feature selection
On the extended set, a correlation matrix keeps only the features with a correlation of at least 0.5 with the carry: ball speed (0.73) and launch angle (0.57). Apex and dispersion are dropped.
05
Linear regression
Trained on half of the shots and tested on the other half (the training function also supports K-fold). The model is then used to predict the carry of new shots and of five typical scenarios.

Results

ModelFeaturesResult
KNN, univariate (k=3)Ball speedRMSE 3.90 m
KNN, multivariate (k=1)Ball speed + Launch angleRMSE 4.29 m
KNN, multivariate (k=3)Ball speed + Launch angle + ApexRMSE 4.86 m
Linear regression (1,000 shots)Ball speed + Launch angleRMSE 2.40 m · R² 0.85

On an average carry of 180 m, the linear model is off by about 2.4 m, around 1.3%. Each extra unit of ball speed adds about 1.1 m of carry, and each extra degree of launch angle about 1.6 m. Ball speed is the feature that explains the most, in every model.

What I Took From It

This one is an experiment, not a product. It was a hands-on way to practise the basics of machine learning on data I know well: preparing the data, ranking features, tuning a hyperparameter, validating on unseen data and reading the error in meters rather than in abstract numbers. The simplest model, a linear regression on two well-chosen features, ends up being the most accurate.
